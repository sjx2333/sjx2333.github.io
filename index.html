核心要点

开源免费 · GPL 保护

KOTOBA·AI 为开源免费软件（GPL-3.0 协议），任何人可自由使用、修改、分发。GPL 的「传染性」保证任何基于本软件的衍生作品必须同样开源——任何人都不能拿它闭源商用或改成封闭软件出售，您的劳动成果始终是开放的。

100% 本地存储 · 零云端上传

您的所有数据 —— 包括 AI 模型 API Key（默认 DeepSeek）、学习笔记、答题记录、错题本、知识库进度、个人配置 —— 均以 JSON 文件形式存储在您电脑本地。KOTOBA·AI 不包含任何数据上传、云端同步、遥测采集或远程存储机制。您可以随时通过「设置 → 清除数据」一键删除全部数据，或手动删除程序目录下的数据文件。

联网仅限 AI 调用 · 其余功能完全离线

KOTOBA·AI 仅在以下场景连接网络：向您所选 AI 模型服务商的 API（默认 DeepSeek，可在设置页切换小米 MiMo）发送学习笔记和答题内容，以生成题目和批改反馈。除此之外的全部功能 —— 历史记录查看、错题本复习、艾宾浩斯记忆系统、知识库管理 —— 均可完全离线使用，无需网络连接。除所选 AI 模型服务商外，没有任何第三方服务器会接触到您的学习数据。

1. 信息收集与使用

KOTOBA·AI 是一款本地运行的桌面软件。我们不收集、不存储、不上传您的任何个人信息。您在软件中产生的所有数据（详见第 2 条）仅保存在您设备的本地文件系统中，我们无法访问，也不会访问。

当您使用 AI 出题和批改功能时，您输入的笔记内容和答题数据会被发送至您所选 AI 模型服务商的 API 服务器（默认 DeepSeek，可在设置页切换小米 MiMo）进行处理。这是唯一涉及数据传输的场景。数据由所选服务商（DeepSeek / 小米 MiMo）按其自身隐私政策处理，详情请参阅 DeepSeek 隐私政策 与 小米 MiMo 平台说明。

2. 本地存储的数据类型

以下数据存储在您设备上（位于 KOTOBA·AI 程序目录中），均不会上传至任何服务器：

  • API 密钥：您的 AI 模型 API Key（默认 DeepSeek，可配置小米 MiMo），用于调用 AI 服务
  • 学习笔记：您粘贴的语法笔记和单词列表
  • 答题记录：每道题的作答内容、AI 批改反馈和得分
  • 错题本：被自动收录的错误题目及错误详情
  • 知识库：已学习语法点的追踪数据和艾宾浩斯复习进度
  • 个人设置：级别偏好、主题选择、教材选择等配置

3. 数据安全

您的数据安全完全取决于您对自己电脑的保护。您应当：

  • 妥善保管您的 AI 模型 API Key，不要分享给他人

KOTOBA·AI 无法访问您的设备，因此无法为数据丢失或泄露承担责任。建议定期备份您的学习数据。

使用说明

快速上手 KOTOBA·AI，5 分钟搞定

1

获取 AI API Key（默认 DeepSeek，可切换小米 MiMo）

前往 DeepSeek 开放平台 或 小米 MiMo 开放平台 注册账号并创建 API Key。

  • 在设置页面的「厂商」下拉中选择你的模型厂商，输入对应 API Key
  • Key 仅保存在你电脑本地，不会上传到任何服务器
  • AI 模型 API 采用按量计费，每次出题 + 批改约花费 ¥0.01 左右，新用户通常有免费额度
2

输入本日语法笔记

将今天学到的语法内容粘贴到笔记框中。没有严格的格式要求，但建议按如下结构整理，AI 理解会更准确：

建议格式：语法点 / 接续 / 中文意思 / 例句
例如：〜てから / Vて形 + から / 做完…之后 / 朝ごはんを食べてから、学校に行きます。

也可以在教学材料中批量复制粘贴，AI 会自动提取语法点。选填「今日单词」可让 AI 在出题时融入新词汇。

3

开始练习，逐题翻译

点击「开始训练」后，AI 会根据你的笔记和所选级别生成翻译题：

  • 每道题会展示一个使用场景和一句中文，你需要将其翻译成日语
  • 在输入框中输入日语翻译，按 Enter 键提交
  • 如果有词汇提示，可以点击展开查看
  • 题目难度会根据你的表现动态调整
4

查看批改反馈

提交答案后，AI 会逐项分析你的翻译：

  • 正确的地方：你做得好的部分
  • 需要注意的地方：错误点、正确写法和详细解释
  • 更自然的说法：让你的日语更地道的建议

得分 ≥ 8 分可以选择「加大难度」挑战更难题目；得分较低可以选择「换道同类题再练」巩固薄弱语法，或「修改重答」同一道题。

5

获取当日学习总结报告

完成全部题目后，系统会自动生成：

  • 统计仪表盘：答题数、平均分、高分题、薄弱项一目了然
  • 复习笔记（Markdown）：包含所有语法点、正确/错误分析和改进建议
  • 点击「下载 .md 文件」可将笔记保存到本地，方便日后复习
  • 可选择将本次语法点保存到知识库，系统会根据艾宾浩斯记忆曲线自动安排复习
6

遇到疑问，随时答疑

练习之外遇到不懂的句子或题目，可以在导航栏进入「答疑」，支持 文字 / 图片 / PDF 三种输入方式：

  • 文字：直接粘贴日语句子，选择解析模式即可
  • 图片 / PDF：上传题目截图或文档，自动识别日文内容
  • 模式 A/B/C：带答案判分 / 自己作答请 AI 评判 / 纯题目请 AI 解题
  • 解析出的知识点可「保存到知识库」或「去练习」生成同类题型巩固
